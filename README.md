# Back to the Basics: SHELL SCRIPT BASICS

Para aspirantes a **DevOps Engineer**, é essencial conhecer shell scripts ou bash scripts.  

Atualmente não se cria mais shell scripts para automação completa, mas usamos scripts junto com ferramentas de automação e para tarefas ad-hoc.  

Por exemplo, se você usar a opção de user data da AWS, há uma chance de usar um shell script dentro dela. Outro exemplo é que, ao criar imagens AMI usando um packer, você acabará usando um shell script para a configuração da AMI. Além disso, há casos em que é preciso usar shell scripts com ferramentas de gerenciamento de configuração, contêineres, etc.  

Além disso, o shell script é útil para tarefas de desenvolvimento repetíveis. Por exemplo, pode ser a criação de uma VM Vagrant com o software essencial ou a configuração do próprio ambiente de desenvolvimento.  

Nos diretórios deste repositório são utilizados os seguintes comandos de shell script:

- echo
- read
- if
- for
- while
- cut
- sed
- awk
- uniq
- grep
- print
- array
